# Instance data

The instances in this directory are adaptations of
[PGLib-OPF](https://github.com/power-grid-lib/pglib-opf), maintained by the IEEE PES
Task Force on Benchmarks for Validation of Emerging Power System Algorithms.
They are distributed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

[SOURCES.tsv](SOURCES.tsv) lists the source cases for every bundled `.m` file.
Paths are relative to this directory. Source names are separated by semicolons,
in the order recorded in the instance, including repeated source cases.
The original authors, copyright notices, references, and source links are retained
in [PGLib-OPF-sources.txt](../../LICENSES/PGLib-OPF-sources.txt), alongside the
[PGLib-OPF license notice](../../LICENSES/PGLib-OPF.txt).

The bundled instances contain modified network data and additional busbar data.
Generated cases may combine several PGLib networks. The source lists and
generation parameters recorded in the instance files are retained.

When redistributing these data, include this file, `SOURCES.tsv`, and the two
PGLib-OPF notice files linked above. Preserve the credits, license links, and
indications of modifications, and identify any further changes.
